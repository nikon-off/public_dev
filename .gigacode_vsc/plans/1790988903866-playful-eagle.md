# Интеграция Unica в GigaCode

## Цель

Подключить Unica (MCP-сервер для разработки на 1С:Предприятии) к GigaCode в VS Code, чтобы агент мог работать с метаданными, формами, СКД и другими объектами 1С.

---

## Этап 1: Установка Rust toolchain

**Цель:** Установить Rust компилятор и сборщик на Windows x64.

### Шаги:

1. **Скачать и установить rustup** — инсталлятор с официального сайта rust-lang.org
   - Использовать установщик `rustup-init.exe` (stable, default target: x86_64-pc-windows-msvc)
   - Добавить в PATH (стандартная опция установщика)

2. **Проверить установку:**
   ```powershell
   rustc --version
   cargo --version
   ```

3. **Установить C++ Build Tools** — требуется для сборки некоторых Rust-критов на Windows:
   - Установить Microsoft C++ Build Tools (через Visual Studio Installer)
   - Или установить через `vcpkg` / скачав с microsoft.com

---

## Этап 2: Сборка Unica из исходников

**Цель:** Получить готовый бинарник `unica.exe` для Windows x64.

### Шаги:

1. **Клонировать репозиторий** (уже выполнено, но нужно убедиться что полная версия):
   ```powershell
   git clone https://github.com/IngvarConsulting/unica.git C:\dev\IngvarConsulting\unica
   ```

2. **Собрать проект:**
   ```powershell
   cd C:\dev\IngvarConsulting\unica
   cargo build --release --bin unica
   ```

3. **Проверить результат:**
   - Бинарник должен быть в: `C:\dev\IngvarConsulting\unica\target\release\unica.exe`
   - Проверить запуском: `unica.exe --help`
   - Ожидаемый вывод: версия и список поддерживаемых MCP-методов

## Этап 4: Настройка gigacode.json

**Цель:** Добавить MCP-сервер Unica в конфигурацию GigaCode.

### Изменение файла:
`C:\dev\public_dev\.gigacode_vsc\gigacode.json`

### Добавить MCP-сервер:

```jsonc
{
  "mcpServers": {
    "context7": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    },
    "unica": {
      "type": "stdio",
      "command": "C:\\dev\\IngvarConsulting\\unica\\target\\release\\unica.exe",
      "env": {
        "UNICA_HOST_CONTEXT_REQUIRED": "1"
      }
    }
  },
  "snapshot": false,
  "skills": {
    "paths": [
      ".gigacode_vsc/skills",
      ".gigacode_vsc/skills/unica"
    ]
  }
}
```

### Разрешения (опционально, по желанию пользователя):

Можно настроить разрешения для инструментов Unica:
```jsonc
"permission": {
  "unica_*": "ask",       // требовать подтверждение для всех инструментов
  "unica_docs": "allow",   // документация — автоматически
  "unica_run": "ask"       // запуск 1С — с подтверждением
}
```

## Этап 5: Проверка интеграции

**Цель:** Убедиться что Unica работает с GigaCode.

### Шаги:

1. **Перезапустить VS Code** (или перезагрузить окно) для применения новой конфигурации

2. **Проверить подключение MCP-сервера:**
   - Открыть палетку команд GigaCode (Ctrl+P)
   - Команда `/mcps` — должен появиться сервер `unica` со статусом `connected`

3. **Протестировать базовый инструмент:**
   - Попросить агента вызвать `unica.run` с пустыми аргументами `{}`
   - Ожидаемый результат: словарь доступных операций (без запуска 1С)

4. **Проверить доступность навыков:**
   - В чате попробовать: `/unica:meta-info` или просто попросить агента использовать навык
   - Навыки должны быть доступны в контексте

## Возможные проблемы и решения

### Проблема 1: Сборка не проходит из-за C++ ошибок
**Решение:** Установить Microsoft C++ Build Tools через Visual Studio Installer (компонент "C++ build tools" + "Windows 10/11 SDK")

### Проблема 2: Бинарник не запускается — нет DLL
**Решение:** Установить Visual C++ Redistributable с microsoft.com

### Проблема 3: MCP-сервер не подключается
**Решение:**
- Проверить путь к бинарнику в gigacode.json (экранировать обратные слеши)
- Проверить что `UNICA_HOST_CONTEXT_REQUIRED=1` установлен
- Запустить бинарник вручную и посмотреть вывод в stderr

### Проблема 4: Навыки не загружаются
**Решение:**
- Проверить что SKILL.md файлы имеют правильный формат (frontmatter с name/description)
- Проверить путь в `skills.paths`
- Перезапустить VS Code
