Speech-to-Text Transcriber - Инструкция по запуску
=====================================================

ВАРИАНТ 1: Запуск через .bat файл (рекомендуется)
--------------------------------------------------
Просто дважды кликните на файл: start_transcriber.bat

Этот файл:
1. Откроет командную строку (cmd.exe)
2. Активирует Anaconda base environment
3. Активирует conda окружение whisper_env
4. Перейдёт в директорию со скриптом
5. Запустит python main.py


ВАРИАНТ 2: Создание .exe файла
------------------------------
Если вы хотите иметь .exe файл вместо .bat:

1. Дважды кликните на make_exe.bat
   - Будет создан SED-файл для iexpress

2. В открывшемся окне выполнится команда:
   iexpress /N /Q /M make_exe.sed
   
   ИЛИ выполните вручную в командной строке:
   iexpress /N /Q /M make_exe.sed

3. Будет создан файл start_transcriber.exe, который можно запускать двойным кликом


ВАРИАНТ 3: Альтернативный .bat файл (без нового окна)
-----------------------------------------------------
Файл run_transcriber.bat запускается в текущем окне cmd.exe


Примечания:
-----------
- Убедитесь, что пути в файлах соответствуют вашей системе:
  * C:\Users\Kolya\anaconda3\Scripts\activate.bat
  * C:\Users\Kolya\anaconda3
  
- Если путь к Anaconda отличается, отредактируйте .bat файлы

- Окружение conda должно называться "whisper_env"
  Проверить: conda env list
  Создать если нет: conda create -n whisper_env python=3.x


Файлы проекта:
--------------
- main.py              - Основной скрипт транскрипции
- start_transcriber.bat - Запуск с открытием нового окна cmd.exe
- run_transcriber.bat   - Запуск в текущем окне
- make_exe.bat          - Скрипт для создания .exe файла
- make_exe.sed          - Конфигурация для iexpress (создаётся автоматически)
- README_RUN.txt        - Этот файл инструкций
