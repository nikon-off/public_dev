# AudioVideoSyncer

Консольная утилита для бесшовного объединения видео (без звука) и аудио с возможностью временного смещения видеоряда.

## Ключевые особенности

- **Lossless-качество** — объединение происходит без перекодирования, оригинальное качество сохраняется
- **Контроль памяти** — мониторинг потребления RAM с защитой от превышения лимита (3 ГБ по умолчанию)
- **Интерактивный CLI** — удобный диалоговый режим работы и поддержка аргументов командной строки
- **Визуальный прогресс** — отображение прогресса обработки в реальном времени
- **Подробное логирование** — все события записываются в файл для отладки

## Предварительные требования

### Python 3.8+

Для работы приложения требуется установленный Python версии 3.8 или выше.

Проверить версию:
```bash
python --version
```

### FFmpeg и FFprobe

Приложению необходимы бинарные файлы FFmpeg и FFprobe. По умолчанию они ожидаются в директории:

```
C:\ffmpeg\bin\ffmpeg.exe
C:\ffmpeg\bin\ffprobe.exe
```

**Скачать FFmpeg:** [https://ffmpeg.org/download.html](https://ffmpeg.org/download.html)

После скачивания распакуйте архив и поместите бинарные файлы в указанную директорию, либо измените пути в файле `config/settings.py`.

## Использование

### Интерактивный режим

Запустите утилиту без аргументов для начала диалога:

```bash
sync-av
```

Программа предложит ввести:
1. **Путь к видеофайлу** — проверит существование файла
2. **Путь к аудиофайлу** — проверит существование файла
3. **Смещение в секундах** — по умолчанию 0.0 (нажмите Enter для значения по умолчанию)

После ввода параметров программа запросит подтверждение начала синхронизации.

**Пример диалога:**
```
=== Интерактивный режим синхронизации ===

Введите путь к видеофайлу: C:\movie.mp4
Введите путь к аудиофайлу: C:\sound.mp4
Введите смещение в секундах (или нажмите Enter для 0.0): 1.5

=== Параметры синхронизации ===
Видеофайл: C:\movie.mp4
Аудиофайл: C:\sound.mp4
Смещение:  1.5 сек.

Начать синхронизацию? [y/N]: y
```

### Режим аргументов командной строки

Передайте все параметры сразу при запуске:

```bash
sync-av --video "C:\movie.mp4" --audio "C:\sound.mp4" --offset 1.5
```

### Описание флагов

| Флаг | Тип | Описание |
|------|-----|----------|
| `--video` | str | Путь к видеофайлу (обязателен в режиме аргументов) |
| `--audio` | str | Путь к аудиофайлу (обязателен в режиме аргументов) |
| `--offset` | float | Смещение видеоряда в секундах (по умолчанию 0.0) |

**Важно:** Смещение применяется к видеопотоку. Положительное значение задерживает видео относительно аудио.

### Назначение модулей

| Модуль | Описание |
|--------|----------|
| `main.py` | CLI интерфейс на базе Click, обработка исключений |
| `config/settings.py` | Константы: пути к FFmpeg, максимальный лимит памяти |
| `core/synchronizer.py` | Класс-оркестратор, управляющий полным циклом синхронизации |
| `core/media_processor.py` | Низкоуровневые вызовы FFmpeg/FFprobe, построение команд |

| `utils/file_utils.py` | Генерация имени выходного файла с суффиксом `_synced` |
| `utils/memory_monitor.py` | Мониторинг RAM через psutil, защита от переполнения |
| `utils/logger.py` | Настройка логгера: INFO в консоль, DEBUG в файл |

## Логирование и отладка

### Файл лога

Все события записываются в файл `syncer.log` в корне проекта.

**Уровни логирования:**
- **INFO** — основные этапы работы (выводится также в консоль)
- **DEBUG** — подробная техническая информация
- **WARNING** — предупреждения (например, потребление памяти > 80% от лимита)
- **ERROR** — ошибки валидации, выполнения команд
- **CRITICAL** — критические ошибки (превышение лимита памяти)

### Поиск причин ошибок

Если приложение завершилось аварийно:

1. Откройте файл `syncer.log`
2. Найдите записи с уровнем `ERROR` или `CRITICAL`
3. Изучите стектрейс (записывается автоматически при необработанных исключениях)

**Пример типичной ошибки:**
```
2024-01-15 10:30:45 - syncer - ERROR - Файл не найден: C:\missing_video.mp4
```

## Тестирование

### Запуск тестов

```bash
pytest
```

### Что проверяют тесты

| Тестовый модуль | Проверяемый функционал |
|-----------------|------------------------|
| `test_validators.py` | Валидация существования файлов, проверка корректности смещения (отрицательные значения, превышение длительности) |
| `test_media_processor.py` | Парсинг метаданных через ffprobe, построение команды ffmpeg (порядок аргументов, наличие обязательных флагов) |
| `test_progress_tracker.py` | Отслеживание прогресса обработки |

Тесты используют mock-объекты для изоляции от внешних зависимостей (FFmpeg, файловая система).

## Выходной файл

Результат синхронизации сохраняется в той же директории, что и исходное видео, с суффиксом `_synced`:

```
Исходный:  C:\Users\Doc\movie.mp4
Результат: C:\Users\Doc\movie_synced.mp4
```
